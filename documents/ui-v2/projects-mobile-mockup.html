Stash for Android: projects and tasks

The desktop project page as a stack: drawer → project → task. Same tokens, touch geometry (48px targets, 44px+ rows). Task mentions in notes render and toggle as on desktop; the @ picker rides above the keyboard.

  1. Projects reuse the drawer, bar, group and sheet patterns from mobile-mockup.html; no new colors.
  2. Project and task actions (status, priority, dates, move, copy link, delete) open bottom sheets with 48px rows, like note actions.
  3. The project page and task page are stack screens; Android back returns to the previous one.
  4. The @ picker uses the same floating surface as the formatting bar and stays above the keyboard; it closes on Esc, back, or when the word ends.
